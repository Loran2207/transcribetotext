How a dialog opens

One animation for everything that opens over the page. Press the button to open it, press it again to close it.

The markup it runs on

<div class="ttt-dim"        data-state="open"></div>
<div class="ttt-modal-card" data-state="open"> … </div>

Radix writes data-state for you. A portal that mounts only while it is
open needs no attribute: the class alone runs the enter animation on mount.

The numbers, and where they come from

ValueSource
200ms in, 120ms outRadix Themes ships 200 / 100 for its dialog. Under Emil Kowalski's 300ms ceiling for UI motion.
cubic-bezier(0.16, 1, 0.3, 1)The curve in the Radix dialog documentation and in Radix Themes. An expo-out: quick to start, settles without bouncing.
scale(0.97)Radix Themes. shadcn's 0.95 is more common only because shadcn is installed everywhere; on a large card the same delta reads as a jump.
translateY(6px)Radix Themes moves it 5px. Without it the dialog pops flat instead of arriving.
The dim fades onlyEvery system does this. It never scales and never moves.
The exit is shorterRadix Themes 200/100, Material 1 225/195. Someone who dismissed a dialog is already looking elsewhere.

On a phone the same dialog is a sheet

It has an edge to arrive from, so it slides its own height instead of scaling, on the curve vaul uses for the iOS sheet. No fade, no scale. 

@keyframes ttt-sheet-in  { from { transform: translateY(100%); } to { transform: translateY(0); } }
@keyframes ttt-sheet-out { from { transform: translateY(0); } to { transform: translateY(100%); } }

@media (max-width: 767px) {
  .ttt-modal-sheet[data-state="open"]   { animation: ttt-sheet-in  400ms cubic-bezier(0.32, 0.72, 0, 1) both; }
  .ttt-modal-sheet[data-state="closed"] { animation: ttt-sheet-out 200ms cubic-bezier(0.32, 0.72, 0, 1) both; }
}

The same thing in Framer Motion

const EASE = [0.16, 1, 0.3, 1];

// the dim
initial={{ opacity: 0 }}
animate={{ opacity: 1, transition: { duration: 0.2,  ease: EASE } }}
exit=   {{ opacity: 0, transition: { duration: 0.15, ease: EASE } }}

// the dialog
initial={{ opacity: 0, y: 6, scale: 0.97 }}
animate={{ opacity: 1, y: 0, scale: 1,     transition: { duration: 0.2,  ease: EASE } }}
exit=   {{ opacity: 0, y: 4, scale: 0.99,  transition: { duration: 0.12, ease: EASE } }}

const reduce = useReducedMotion();  // and honour it
