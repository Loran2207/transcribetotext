How a dialog opens

One animation for everything that opens over the page. Press the button and watch it; press it again and watch it close. The width switch shows the same dialog on a phone, where it is docked to the bottom edge and travels its own height instead.

If a surface is built with Framer Motion

  
const EASE_IN  = [0.22, 1, 0.36, 1];
const EASE_OUT = [0.4, 0, 1, 1];

// the dim
initial={{ opacity: 0 }}
animate={{ opacity: 1, transition: { duration: 0.2,  ease: EASE_IN  } }}
exit=   {{ opacity: 0, transition: { duration: 0.16, ease: EASE_OUT } }}

// the dialog
initial={{ opacity: 0, y: 14, scale: 0.965 }}
animate={{ opacity: 1, y: 0, scale: 1,     transition: { duration: 0.26, ease: EASE_IN  } }}
exit=   {{ opacity: 0, y: 8, scale: 0.985, transition: { duration: 0.16, ease: EASE_OUT } }}

// the same dialog on a phone
initial={{ y: "100%" }}
animate={{ y: 0,      transition: { duration: 0.3,  ease: EASE_IN  } }}
exit=   {{ y: "100%", transition: { duration: 0.16, ease: EASE_OUT } }}

const reduce = useReducedMotion();  // and honour it


  
Two rules

  

    

      A stack of dialogs animates only the one that arrives. The layers underneath stay where they are.
      The exit is never longer than the enter. A user who dismissed something is already looking somewhere else.
